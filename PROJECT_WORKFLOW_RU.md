# Основной чат и репозиторий

По поручению пользователя от 25 сентября 2026 года текущий чат становится основным для разработки Black Swordsman 3D. Канонический репозиторий: https://github.com/Cheb1996/Black-Swordsman-3D, ветка `main`.

Разработка ведётся в рабочей копии этого репозитория. Перед изменениями проверяются `git status`, адрес `origin` и обновления GitHub. Завершённая работа коммитится и отправляется через авторизованный Git или подключённый GitHub API. Правила: [AGENTS.md](AGENTS.md).

## Состояние переноса

Готовый выпуск — v14.0.0. Исходный коммит: `43bcc9513d1909102efb6946fbc9fde4ef3274f5`.
SHA-256 APK: `d4d5e3ccbb8105da7a9f7fb0951abf9d9f85dc7c98e00b20cb2c98e1a8c6a373`.

Код v9–v14 и исходная история сохранены в ранее подготовленной резервной копии проекта. Их импорт в GitHub пока не завершён: в `main` остаётся игровая версия v8 и новые правила разработки. Не начинать новые изменения игры на базе v8 и не считать обновление документации публикацией v14.

Для переноса оригинальной истории нужен обычный авторизованный `git push`. Подключённый GitHub API позволяет менять файлы, но рабочая среда Git пока не авторизована. Временная задача GitHub Actions для импорта удалена; использовать её для обхода отсутствующей авторизации не следует.

При продолжении восстановить исходную v14, получить актуальную `origin/main`, объединить обе истории с сохранением коммитов и отправить без force-push. После успешного импорта обновить этот статус и проверить контрольную сумму APK. Закрытый ключ выпуска и `.signing.local` остаются вне GitHub.

Отчёты v14 содержат 45 пройденных программ проверок. Проверки на физическом телефоне ещё не было. Настройка основного чата — рабочее правило проекта; настройки интерфейса ChatGPT этим не меняются.
