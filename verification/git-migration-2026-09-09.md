# Проверка переноса в GitHub

Канонический репозиторий: https://github.com/Cheb1996/Black-Swordsman-3D.
Импортирована версия 8.0, без изменений игрового кода и игровых ресурсов.
Перед переносом 795 файлов сверены побайтово с сохранённым архивом исходников v8.

- Все 19 программ из `./test.sh` прошли повторно в git-копии проекта.
- `./build.sh debug` и `./build.sh release` завершились успешно.
- Оба APK проверены через `tools/verify_apk.py`: содержимое ZIP, DEX, ресурсы,
  manifest, выравнивание и подпись корректны.
- Подпись выпуска совпадает с ранее опубликованным APK v8. Тестовая сборка
  использует отдельный ключ.
- `tools/package_release.py` создаёт архив из отслеживаемых Git файлов;
  отсутствие закрытого ключа и локальных паролей в архиве проверено.
- В `releases/v8.0` помещён исходный опубликованный APK, без пересборки и замены.
  SHA-256: `ea08a9c01e580746fd0ba82d75bdd9f382b281423fb7349db6817bd9beb5a92c`.

Скрипты сборки больше не зависят от соседней папки `downloads`. Приватные файлы
подписи, промежуточные сборки и старые ZIP-архивы исключены из Git. Новые отчёты
проверки записываются в `build/verification`; исторические отчёты сохранены.

Проверка на физическом Android-устройстве не выполнялась.
