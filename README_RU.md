# Black Swordsman 3D 8.0 — Mycelium under the Red Star

Неофициальная офлайн фан-игра для Android по мотивам арки «Чёрный мечник». Нативный Java/OpenGL-проект с девятью главами, боем от третьего лица и сюрреалистической физической песочницей.

Готовый установочный файл: `BlackSwordsman3D-v8.0.apk`. Требования: Android 7.0 или новее, OpenGL ES 3.2. Пакет `com.danil.blackswordsman`, versionCode 8, targetSdk 35. Подпись сохраняется от предыдущих версий. APK можно установить как обновление. Старый прогресс глав читается; полные контрольные точки v6 и v7 мигрируют в v8.

## Что добавлено

v8 добавляет 12 материалов с картами цвета и нормалей/шероховатости 512×512, обновлённые скелетные оболочки и позы, составные конечности животных и странных существ, тусклое красное светило и объёмные облака. Растительность расширена на 32 вида грибов и 16 растений. Восемь редких грибов дают временные способности; сбор — кнопкой **ДЕЙСТВИЕ**. Подробный каталог — [FLORA_RU.md](FLORA_RU.md).


Описание изменений и проверок: [RELEASE_NOTES_RU.md](RELEASE_NOTES_RU.md).

Карта 898,09×898,09 м — ×10 по площади относительно v6, плюс полоса океана для плавания. Добавлены 24 места, извилистая река с притоком, три озера, два оазиса, плавучесть всех свободных предметов, водные обломки и игрушечные кораблики. Девять сред с дорогами, мостом, руинами, городами, лесами, стоками и астральными зонами. Сюжет требует пройти маршрут, взаимодействовать с целью, завершить волны и добраться до выхода. В первой главе нужно освободить Пака.

Сохранены 240 геометрических вариантов предметов и 720 основных размещений, аптечки, десять видов находок, НЛО и странные существа. Полный каталог: [CATALOG_RU.md](CATALOG_RU.md). Временные эффекты и формы не изменяют постоянную прокачку.

## Сборка из исходников

В репозитории находится закреплённый набор компилятора, Android API jar, упаковщика и подписывающего инструмента. Требуется Linux x86_64, Java 17, Python 3, Bash, `rg`, системные glibc/libstdc++/zlib. Проверка контрольных сумм зависимостей выполняется автоматически. Загрузка Gradle или Android SDK не нужна.

```sh
chmod +x build.sh test.sh
./test.sh
./build.sh debug
python3 tools/verify_apk.py --debug
```

Тестовый APK появляется в `dist/BlackSwordsman3D-v8.0-debug.apk`. Он имеет отдельную подпись и не устанавливается поверх опубликованного APK. Для внешнего набора тех же зависимостей можно указать `BS_ANDROID_TOOLCHAIN`. Состав и хеши указаны в `toolchain.lock.json`; лицензии — в `toolchain/licenses`.

Закрытый ключ обновлений не входит в публичный репозиторий. Для совместимого выпуска используются `./build.sh release`, прежний локальный ключ `keystore/black-swordsman.keystore` и переменные `BS_KEYSTORE_PASSWORD` / `BS_KEY_PASSWORD`. Другой путь и псевдоним задаются через `BS_KEYSTORE` / `BS_KEY_ALIAS`. Настройки можно хранить в исключённом из Git файле `.signing.local`. Пароли не записываются в команды подписи. Проверка выпуска: `python3 tools/verify_apk.py`; результаты записываются в `build/verification`, не изменяя исторические отчёты.

Для упаковки исходников и установочного ZIP сохраните результаты `./test.sh` и `./build.sh release` в `build/v8-final-tests.log` и `build/v8-final-build.log`, выполните проверку APK, затем `python3 tools/package_release.py`. Скрипт берёт отслеживаемые Git файлы, исключает ключи и архивы и записывает результат в `dist/`.

При сборке 500 сеток игрушек/находок, 96 сеток растений/грибов и 24 карты материалов заново запекаются из текущих определений, включая два уровня детализации. Для повторного создания оригинальных WAV:

```sh
python3 tools/generate_audio.py
```

Статистики и категории 33 типов врагов и существ вынесены в `app/src/main/assets/enemies.tsv`, параметры 240 предметов — в `app/src/main/assets/items.tsv`. `core-sources.txt` — общая граница независимого от Android ядра для сборки и тестов. Модули расширения v7: `WaterField`, `WaterGeometry`, `WaterRenderer`, `RegionLayout`, `CreatureSystem`, `UfoEncounters`. Модули v8: `AnimationSystem`, `SurfaceLibrary`, `MaterialTexture`, `CloudField`, `CloudRenderer`, `FloraCatalog`, `FloraGeometry`, `FloraWorld`, `FloraRenderer`, `MushroomEffects`. Основные модули: `CombatSystem`, `CollisionMath`, `ContactSolver`, `SimulationClock`, `QuestSystem`, `ExplorationSystem`, `NavigationSystem`, `SnapshotCodec`, `SkinGeometry`, `TouchOwnership`, `GameSettings`.

## Проверки

В `verification/` находятся результаты проверок ядра, полного прохождения и пакета. Полный бот проходит главы последовательно, перемещается командами джойстика, переносит грузы, атакует врагов, достигает выходов и выбирает улучшения. Для проверки переходов используется неуязвимость; баланс для человека этим тестом не измеряется.

Скрипт `tools/render_v8_qa.py` показывает экспортированные поверхности моделей вне Android. Это проверка геометрии, а не скриншот запущенной игры. Устройство или Android-эмулятор в среде разработки отсутствуют; работа драйвера GLES, звук, датчики, FPS и нагрев требуют проверки на телефоне. Физика — компактный собственный решатель с упрощёнными коллизиями декоративных форм.
