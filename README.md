# Black Swordsman 3D

Неофициальная офлайн фан-игра для Android: Java, OpenGL ES 3.2, вид от третьего лица, девять сюжетных глав и физическая песочница. Текущая версия — **8.0**.

**[Скачать подписанный APK v8.0](https://github.com/Cheb1996/Black-Swordsman-3D/raw/refs/heads/main/releases/v8.0/BlackSwordsman3D-v8.0.apk)** · [Описание игры и управление](README_RU.md) · [Изменения](RELEASE_NOTES_RU.md)

Нужны Android 7.0+ и OpenGL ES 3.2. Опубликованный APK сохраняет прежнюю подпись для обновления установленной игры. [Контрольная сумма и сведения о пакете](releases/v8.0/package.json).

## В проекте

- Мир с лесами, водоёмами, океаном, строениями, НЛО и физическими предметами.
- 240 вариантов предметов, игрушки, находки и временные превращения.
- Биологические, магические и механические существа; скелеты и ragdoll.
- 32 вида грибов, 16 растений, восемь грибных способностей, объёмные облака и красное светило.
- Исходники, ресурсы, генераторы моделей/текстур/звука, инструменты сборки и 19 программ проверок.

Каталоги: [предметы](CATALOG_RU.md), [грибы и растения](FLORA_RU.md). Результаты ранее выполненных проверок — в [verification](verification).

## Сборка

Linux x86_64, Java 17, Python 3, Bash и ripgrep (`rg`). Закреплённые Android-инструменты и их лицензии включены в репозиторий.

```sh
git clone https://github.com/Cheb1996/Black-Swordsman-3D.git
cd Black-Swordsman-3D
./test.sh
./build.sh debug
python3 tools/verify_apk.py --debug
```

Результат: `dist/BlackSwordsman3D-v8.0-debug.apk`. Тестовый APK использует отдельный ключ; для обновления установленной игры скачайте подписанный выпуск выше. [Настройка выпуска с прежней подписью](README_RU.md#сборка-из-исходников).

Все дальнейшие изменения ведутся в этом репозитории; порядок работы записан в [AGENTS.md](AGENTS.md). Ключ подписи и пароли хранятся отдельно от публичного кода. Каталоги `build/` и `dist/` создаются локально; опубликованный APK лежит в `releases/v8.0/`.

## Границы проверки

Ядро и пакет проверены на компьютере. Проверки на физическом Android-устройстве не было: GLES-драйвер, FPS, звук, датчики и нагрев требуют отдельного прогона. Изображения в `verification/` — предварительный просмотр геометрии, а не кадры с телефона.
